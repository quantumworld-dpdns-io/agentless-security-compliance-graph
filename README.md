# agentless-security-compliance-graph

> Agentless internal security compliance graph – maps devices, AD accounts, CVEs, and policy gaps without a heavy agent (eBPF/OTel/DuckDB/LangGraph)

## Overview

This repository is part of the [quantumworld-dpdns-io](https://github.com/quantumworld-dpdns-io) Wild SaaS & Tech Development initiative.

```bash
# Clone the repo

cd agentless-security-compliance-graph
```
