# Contributing to agentless-security-compliance-graph

1. Fork the repository and create your feature branch from `main`.
2. Commit your changes with clear, descriptive messages.
3. Run `make lint && make test` before committing.
4. Open a pull request describing what you changed and why.
5. Ensure all CI checks pass before requesting a review.

## Development Setup

```bash
make install
make test
make lint
```

## Commit Convention

Use conventional commits: `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `ci:`, `chore:`
